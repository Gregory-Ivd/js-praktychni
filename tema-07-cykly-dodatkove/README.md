# Тема 7. Цикли: додаткове завдання

Додаткове завдання до практичної роботи «Цикли» (курс «Основи програмування», Moodle). Практична в Moodle: [відкрити](https://vo.uu.edu.ua/mod/assign/view.php?id=272930&action=view) (потрібен вхід у Moodle).

## Чому воно лежить тут, а не в Moodle

Завдання «Практична робота Цикли» в Moodle приймає один файл. Чотири основні задачі вже здано в ньому. Щоб не замінювати здану й оцінену роботу, додаткове завдання винесено сюди. В основному файлі є посилання на цю сторінку.

## Умова

Спитати користувача, скільки він хоче отримати привітань, і вивести таку кількість привітань «Слава Україні!», пронумерувавши їх. Потім написати «Героям слава __ раз», узгодивши іменник з числівником.

Я зрозумів це так: у фінальному рядку стоїть те саме число, яке ввів користувач.

## Що робить програма

1. Показує вікно з питанням (`prompt`).
2. Якщо натиснули Cancel, пише, що введення скасовано.
3. Перетворює відповідь на число.
4. Перевіряє, що число ціле й не менше 1.
5. Циклом `for` виводить привітання з номерами.
6. Підбирає слово: «раз», «рази» або «разів». Для цього дивиться на останню цифру (`% 10`) та останні дві цифри (`% 100`).
7. Виводить фінальний рядок.

Кожен крок підписано коментарем у самому файлі.

## Приклади

| Ввід | Фінальний рядок |
|---|---|
| 1 | Героям слава 1 раз! |
| 3 | Героям слава 3 рази! |
| 5 | Героям слава 5 разів! |
| 11 | Героям слава 11 разів! |
| 21 | Героям слава 21 раз! |
| 22 | Героям слава 22 рази! |
| 0, -1, 2.5, слово, порожньо | Потрібне ціле число, не менше 1. |
| Cancel | Введення скасовано. |

Ці результати я перевірив запуском програми.
