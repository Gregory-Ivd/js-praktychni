# Практичні з JavaScript

Мої практичні роботи з курсу «Основи програмування» (Університет «Україна», група ЗІПЗ-26-1, перший курс). Основні роботи я здаю в Moodle. Сюди виношу лише те, що там не вміщається.

## Чому цей репозиторій існує

У Moodle до завдання «Практична робота Цикли» можна прикріпити лише один файл. Основну роботу з чотирма задачами я здав 24.10.2026. Додаткове завдання (привітання «Слава Україні!» з узгодженням слова «раз») я зробив пізніше, і другим файлом його додати не можна.

Тому додаткове завдання лежить тут, а в основному файлі практичної є посилання на нього. Так викладачка бачить усе в одному місці: в Moodle основну роботу, а за посиланням додаткову.

## Як відкрити роботу

Найпростіше перейти за посиланням у стовпці «Відкрити в браузері». Програма сама задасть питання у вікні. Можна й завантажити файл `index.html` із папки практичної та відкрити його двічі клацнувши.
